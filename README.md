# Detector Event Processor
 
A detector measures gamma rays from an unknown sample. You build the classes that read the events and name the isotope.
 
## Setup
1. Install Python, VS Code, and Git.
2. On GitHub click **Code, then Download ZIP**. Unzip it and open the folder in VS Code.
3. Open the terminal in VS Code (Terminal, New Terminal).
4. Install the graphing package: `pip install matplotlib`
